# Smoke-test fixtures — NOT ML DATA

These 10 synthetic MP4 files are **pipeline test fixtures only**.

They exist solely to verify:
- dataset discovery
- manifest generation
- source-video grouping
- leakage-safe splitting
- basic OpenCV readability

## Hard rules

- Do NOT train models on these files.
- Do NOT report accuracy, F1, ROC-AUC, or any metric from these files.
- Do NOT describe them as deepfake or real forensic samples.
- Do NOT include them in dataset statistics in the project README or papers.

They are colored noise clips with burned-in text labels, generated by
`ml/scripts/generate_smoketest_fixtures.py` via ffmpeg.

## Layout and grouping

| File | source_video_id | label |
|---|---|---|
| real/smoke_01_real.mp4 | smoke_01 | REAL (0) |
| fake/smoke_01_fake_a.mp4 | smoke_01 | FAKE (1) |
| real/smoke_02_real.mp4 | smoke_02 | REAL (0) |
| fake/smoke_02_fake_a.mp4 | smoke_02 | FAKE (1) |
| ... | ... | ... |
| real/smoke_05_real.mp4 | smoke_05 | REAL (0) |
| fake/smoke_05_fake_a.mp4 | smoke_05 | FAKE (1) |

All derivatives of the same `source_video_id` MUST stay in the same split.
That invariant is enforced by `ml/data/validate.py` and covered by pytest.
